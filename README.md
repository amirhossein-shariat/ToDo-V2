# Spark

اپلیکیشن مدیریت کار پیشرفته (تک‌کاربره) با نمای روزانه/هفتگی/ماهانه، اهداف و زیرتسک، نمودار، خروجی گزارش، و کارکرد آفلاین با همگام‌سازی بین دستگاه‌ها.

## استک فنی
- **Frontend:** React + Vite + TailwindCSS + Framer Motion + Recharts + PWA (vite-plugin-pwa) + IndexedDB (idb)
- **Backend:** Python + FastAPI + SQLAlchemy
- **Database:** SQLite

## اجرای لوکال (توسعه)

### Backend
```bash
cd backend
source venv/bin/activate   # ویندوز: venv\Scripts\activate
uvicorn app.main:app --reload --port 8000
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

فرانت روی `http://localhost:5173` بالا می‌آید و درخواست‌های `/api/*` را به بک‌اند (`http://127.0.0.1:8000`) پراکسی می‌کند.

## راه‌اندازی به‌عنوان سرور اصلی (Windows) + دسترسی از همه دستگاه‌ها با Tailscale

هدف: کیس ویندوز همیشه‌روشن به‌عنوان **منبع اصلی داده** عمل می‌کند. مک، آیفون، اندروید و... به‌عنوان کلاینت به آن وصل می‌شوند — چه در همان وای‌فای، چه از هر جای دیگر دنیا (از طریق Tailscale)، و وقتی آفلاین هستند هم اپ کار می‌کند و بعداً همگام می‌شود.

### ۱. نصب پیش‌نیازها روی ویندوز
- [Python 3.11+](https://www.python.org/downloads/) (هنگام نصب گزینه «Add Python to PATH» را تیک بزنید)
- [Node.js LTS](https://nodejs.org/)
- Git (اختیاری، برای `git pull` مستقیم) یا صرفاً دانلود ZIP از ریپو

### ۲. گرفتن کد پروژه روی ویندوز
```powershell
git clone https://github.com/amirhossein-shariat/ToDo-V2.git
cd ToDo-V2
```
(یا ZIP ریپو را از گیت‌هاب دانلود و اکسترکت کنید)

### ۳. ساخت build نهایی فرانت
```powershell
cd frontend
npm install
npm run build
cd ..
```
این پوشهٔ `frontend/dist` را می‌سازد که خودِ بک‌اند FastAPI مستقیماً آن را سرو می‌کند (نیازی به اجرای جدای Vite نیست).

### ۴. راه‌اندازی بک‌اند
```powershell
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```
حالا با باز کردن `http://localhost:8000` روی خود ویندوز، باید کل اپ (نه فقط API) نمایش داده شود.

> برای اینکه سرور با ری‌استارت ویندوز خودکار بالا بیاید، می‌توانید از Task Scheduler ویندوز (اجرای این دستور هنگام ورود کاربر) استفاده کنید.

### ۵. نصب و راه‌اندازی Tailscale (برای دسترسی امن از هر جای دنیا)
Tailscale یک شبکهٔ خصوصی مجازی رایگان (برای استفادهٔ شخصی) می‌سازد که دستگاه‌های شما را بدون نیاز به port-forward یا دامنه، امن به هم وصل می‌کند.

1. روی **ویندوز**: از [tailscale.com/download](https://tailscale.com/download) نصب کنید و با یک اکانت (گوگل/گیت‌هاب/مایکروسافت) لاگین کنید.
2. روی **مک**: از همان سایت اپ macOS را نصب کنید و با **همان اکانت** لاگین کنید.
3. روی **آیفون/اندروید**: اپ Tailscale را از App Store / Google Play نصب و با همان اکانت لاگین کنید.
4. بعد از لاگین همهٔ دستگاه‌ها، در پنل [login.tailscale.com/admin/machines](https://login.tailscale.com/admin/machines) نام و آدرس هر دستگاه دیده می‌شود (چیزی شبیه `windows-pc` با آی‌پی `100.x.y.z`).

### ۶. اتصال از سایر دستگاه‌ها
با روشن بودن Tailscale روی هر دستگاه، از مرورگر به آدرس زیر بروید:
```
http://<نام-یا-آی‌پی-Tailscale-ویندوز>:8000
```
مثلاً: `http://windows-pc:8000` یا `http://100.101.102.103:8000`

سپس از منوی مرورگر گزینهٔ **«Add to Home Screen» / «Install App»** را بزنید تا اپ به‌صورت آیکون مستقل روی آن دستگاه نصب شود (iOS، Android، macOS، Windows همگی از این قابلیت پشتیبانی می‌کنند).

### نحوهٔ کار آفلاین
- همهٔ داده‌ها (تسک‌ها، اهداف) در یک کش محلی (IndexedDB) روی هر دستگاه نگه داشته می‌شوند؛ اضافه‌کردن/ویرایش/تیک‌زدن تسک همیشه فوری و بدون نیاز به اینترنت کار می‌کند.
- وقتی دستگاه به اینترنت/Tailscale وصل شود، تغییرات صف‌شده به‌طور خودکار به سرور ویندوز ارسال (push) و آخرین وضعیت از آن دریافت (pull) می‌شود — فقط رکوردهای تغییریافته رد و بدل می‌شوند تا مصرف داده کمینه باشد.
- یک نشانگر کوچک بالای صفحه وضعیت «آفلاین» یا تعداد تغییرات در صف ارسال را نشان می‌دهد.
- نماهای تحلیلی (آمار تفکیک برچسب، رشته‌های پیوسته) فعلاً فقط آنلاین کار می‌کنند.

### محدودیت مهم
اگر کیس ویندوز خاموش یا بدون اینترنت باشد، بقیهٔ دستگاه‌ها همچنان می‌توانند آفلاین کار کنند (از کش محلی خودشان) اما تا روشن‌شدن مجدد ویندوز و برقراری اتصال، همگام‌سازی بین دستگاه‌ها انجام نمی‌شود.
